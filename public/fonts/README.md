# Typography

Janus uses Söhne through the project owner's stated YC access. Place the licensed webfont at `public/fonts/Sohne.woff2` for local development and deployment. The font binary stays out of this public source repository; it is not covered by the code license.

The locally installed font matches Stripe's `sohne-var` asset observed on October 31, 2026. Shared styles in `src/typography.css` enable `ss01`, the alternate a documented by [Klim Type Foundry](https://klim.co.nz/fonts/soehne/). Headings use light weight and approximately -0.02em tracking; body and control text use regular and medium weights. Font shapes are not stretched or edited. The Janus text wordmark uses Söhne at weight 600 with -0.055em tracking.
